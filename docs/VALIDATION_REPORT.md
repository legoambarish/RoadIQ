# RoadIQ implementation validation

**Overall verdict: PARTIALLY VERIFIED.** Earlier baseline validation included a full 993-image CPU API benchmark, UI flow, and standalone Windows package. In the current PR #18 remediation follow-up, both models have been trained and the real-checkpoint API integration suite passes, but all target accuracy metrics fail and Windows packaging with the new weights has not been tested. The upload contract now also returns a separately labeled experimental image-space indicator; RSQI and percentile remain unavailable without the required measurements/cohort. This is an experimental inspection prototype, not a validated road-condition/safety product.

### Experimental image indicator

Image-analysis contract v1.2 adds `experimental_image_indicator`: actual detector candidate count, exact union of clipped box area as a percentage of full image pixels, predicted pothole-mask pixels as a percentage of the predicted pavement denominator when the mask is available, and a provisional demo score. The score uses `clamp(100 - 10*candidate_count - 3*box_coverage_percent - 2*pothole_fraction_percent, 0, 100)` with unavailable pothole fraction treated as zero. These coefficients are unvalidated demonstration heuristics, not RSQI or a road-condition rating; zero detections return 100 and can be falsely reassuring. Unusable images or unavailable/failed detector inference yield null indicator values; a sole minimum-resolution warning allows a `limited` preview while RSQI remains Unrated. The RSQI percentile remains unavailable because no eligible, compatible scored cohort exists.

Verification of this follow-up: backend unit + real-model integration suite **151 passed** (two dependency deprecation warnings); frontend **15 tests passed**, lint, TypeScript check and Vite production build passed. The low-resolution preview is covered by a service test; it is not an accuracy validation. Windows packaging with the updated response/UI has not been run.

Post-score API smoke check used the configured local detector and segmentation checkpoints with the previously shared limited-preview image: `POST /api/v1/image-analyses` returned contract `image-analysis-v1.2`, indicator status `limited`, provisional score **56.9**, and `rsqi.value=null`; there were no processing errors. This demonstrates that the UI's provisional number is computed and returned for that sample, not that the formula or model output is accurate. A different image with zero detector and pothole-mask outputs can produce **100.0** under this formula, which is prominently disclosed as a potentially false-reassuring result.

## Scientific checks and observed failures

The frozen legacy `scoring.py` and road-segment schema are unchanged from main `c6993d7`. The live API supplies no invented component values and therefore stays Unrated. VDA tests cover no supported detections versus healthy claims, blurry/no-detection cases, unavailable/failed inference, low predicted road coverage and localized potholes independent of average area. A failed mask benchmark remains visible even with zero detector candidates.

The HTTP admission test uses an explicitly blocking **test analyzer** to fill both real inference slots. Health remains responsive, an excess upload receives 503 / Retry-After 2, and completed work releases the slots. This is a threading/backpressure contract test, not model-accuracy evidence. The separate genuine-asset integration gate passed with the actual trained assets and source-heldout inputs; it checks working inference/contracts, not adequate detection accuracy.

Geometry tests cover source-normalized boxes, clipping, four-neighbor mask perimeter, true mask area rather than rectangle area, zero ROI denominator, coordinate-size mismatch, overlapping-tile reconstruction/NMS and extreme-aspect tile coverage. Image tests cover EXIF orientation, glare/low-detail heuristics, resolution/exposure blocking, MIME mismatch, corrupt/animated files and pre-parser oversized/chunked multipart budgets. Algorithm tests do not establish field measurement accuracy.

The first source-group/near-neighbor union collapsed RDD into one component; it was rejected before training. The final audited capture-order split is reproducible but is not a proven route-independent field split. Duplicate exclusions can bias it; within-split near neighbors remain. The semantic holdout is one sequence with 14 pothole-positive frames. Both ROI v2/v3 have zero heldout pothole overlap; the native CPU projection confirms the failure. The v4 attempt was stopped as redundant after source/input equivalence was proved, retaining its incomplete evidence rather than relabelling a new trained result.

The native mask failure sheet shows false pothole pixels on steps/footpath edges. Error metrics, class confusion and IDs are retained in [MODEL_CARD.md](MODEL_CARD.md) and `docs/evidence/roi-*evaluation.json`. Pixel-fraction/area outputs are experimental model predictions; they cannot support trustworthy damage or physical measurements. No model was tuned using these heldout outcomes.

The complete API benchmark has median warm CPU latency 574.053 ms / p95 611.372 ms; load 1,965.560 ms and first request 3,079.848 ms. Longitudinal/transverse candidate counts are zero at confidence .25 (recall zero); alligator TP/FP/FN 77/34/188, pothole 50/65/378. There are 693 no-detection, 153 defect and 147 low-confidence states, all with null RSQI/percentile. Thirteen of 569 source-empty-box frames produce candidates; these are not certified healthy negatives. Conditional intervals and all per-image records are retained in [pipeline summary](evidence/pipeline-benchmark.json) and [compressed records](evidence/pipeline-per-image.json.gz). This run predates only the small additive detector-AP reporting field/reason; it uses unchanged final weights, inference, geometry, thresholds and states. [Execution scope](evidence/pipeline-execution-provenance.json). It excludes browser rendering/network transport, so it is not a full desktop latency claim.

A diagnostic constant-road prediction has ROI IoU .739147 versus the learned .512599 on this road-dominated test sequence. An empty pothole mask has all-image area MAE 110.65 source pixels versus the learned 1,435.81; both have zero pothole overlap. Learned five-class macro IoU .225749 exceeds constant-road .147805, but that does not rescue useful ROI/damage measurement. [Baseline calculations](evidence/roi-diagnostic-baselines.json) are retained with the failure, without changing the frozen model or threshold.

No independent new field set, certified healthy/severity labels, physical scale/depth ground truth, real GPS/time survey collection, eligible RSQI/cohort percentile, material/occlusion validation or commercial redistribution review exists.
